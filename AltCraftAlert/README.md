# AltCraftAlert

Welcome to the official repository for **AltCraftAlert**, a World of Warcraft addon crafted with care by **Dyrella**. 

---

## 🚀 Overview
**AltCraftAlert** is a lightweight World of Warcraft addon designed to help you track your alternative characters' crafting cooldowns, professions, and key metrics at a glance, preventing you from missing out on daily or weekly lockouts.

## ✨ Features
* **Automatic Login Scans:** Instantly checks and reports your character's status upon logging in.
* **Lightweight & Efficient:** Built using native WoW API structures for minimal memory overhead.
* **Slash Command Integration:** Easily trigger manual checks using simple chat commands.

## 🛠️ Installation
1. Download or clone this repository into your World of Warcraft AddOns directory:
   * `Path: <World of Warcraft Location>\Interface\AddOns\AltCraftAlert\`
2. Ensure the folder contains three files:
   * `AltCraftAlert.toc`
   * `AltCraftAlert.lua`
   * `README.md`
3. Launch World of Warcraft and enable **AltCraftAlert** in your Addon menu.

## ⚙️ Usage
Once logged into the game, you can use the following chat command:
* `/aca check` — Runs a manual status check for your active character.
